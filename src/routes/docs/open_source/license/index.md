We have a dual-licensing model for our open source projects. The source code is available under the AGPL-3.0 license for open-source usage. This means you can freely use, modify, and distribute the code as long as you comply with the terms of the AGPL-3.0 license. The license is located in the [OSS_LICENSE.md file](https://github.com/birdflop/web/blob/birdflop/OSS_LICENSE.md) in the Github repository.

For closed-source usage, both commercial and non-commercial, we offer a separate licensing option. This allows you to use our code in proprietary projects without the requirement to disclose your source code. This requires a purchase of a license. Visit the Birdflop Discord to acquire into obtaining these licenses. All other closed-source usage is disallowed.
