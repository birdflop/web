# What is an "Egg"?

An "egg" is a configuration template that defines everything needed for a specific game server to be setup.

An egg contains all the necessary information for Pterodactyl to:

- **Install the server**: Install scripts and commands needed to properly install and setup the server.
- **Configure startup parameters**: Define the startup command and any necessary parameters for the server to run.
- **Setup the environment**: Define the Docker image, configuration files and any other settings.

# What is the Egg Changer?

The Egg Changer is a tool that allows you to switch between different game server eggs quickly and easily. This is useful for switching between spigot/paper, forge, fabric, or to entire other games.

# How to use the Egg Changer

1. Head to the Settings tab of your server.
2. Look for the "Change EGG" section.
3. Select the egg you want to switch to from the dropdown menu.
